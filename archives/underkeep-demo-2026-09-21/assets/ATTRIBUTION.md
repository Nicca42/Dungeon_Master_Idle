# Assets

- Dungeon, village, characters, traps, and treasure: original geometric pixel-style SVG artwork in `src/components/PixelArt.tsx`, created for this project.
- Application icon: original pixel gate/descending-arrow motif generated by `scripts/generate-icon.py`.
- Pixelify Sans: bundled through `@expo-google-fonts/pixelify-sans`; SIL Open Font License. License is included in that package as `LICENSE_FONT`.
- Space Grotesk: bundled through `@expo-google-fonts/space-grotesk`; SIL Open Font License. License is included in that package as `LICENSE_FONT`.
- Lucide icons: `lucide-react-native`, ISC license; see the package license.

All fonts and artwork ship locally. No remote artwork or proprietary D&D assets are used.
